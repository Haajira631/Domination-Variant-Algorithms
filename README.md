The Algorithm computes the Domination number(DN), Total Domination number(TDN) and Power domination number(PDN) of the chemical structures when the SMILES strings is given as the input. 
The code uses RDkit, NetworkX and CP-SAT solver to convert the chemical structures into graph with vertices and edges and then compute.
Output: Number of vertices, Number of edges, IUPAC name of the chemical compound, DN, TDN, PDN.
